# 🌱 Smart Farm — โรงเรียนบ้านทุ่งจำเริง

ระบบเกษตรอัจฉริยะต้นแบบสำหรับ **โรงเรียนบ้านทุ่งจำเริง** ใช้เป็นสื่อการเรียนรู้เรื่องเกษตรอัจฉริยะ (Smart Farm) และ IoT
วัด **ความชื้นและอุณหภูมิในดิน** ของแต่ละแปลง แล้วใช้ข้อมูลนั้นตัดสินใจ **เปิด-ปิดน้ำอัตโนมัติ** พร้อมสั่งงานและตั้งค่าผ่านมือถือได้

> Firmware เวอร์ชัน **2.0.1** · ควบคุม **2 แปลง (ซ้าย / ขวา)** · ใช้งานได้ทั้งผ่านอินเทอร์เน็ต (Blynk) และผ่าน Wi-Fi ของบอร์ดเอง (Web Portal)

## ฮาร์ดแวร์ที่ใช้

| อุปกรณ์ | หมายเหตุ |
|---|---|
| **Waveshare ESP32-S3-POE-ETH-8DI-8RO** (Flash 16MB) | บอร์ดควบคุมหลัก มีรีเลย์ 8 ช่อง, RTC, RS485, PoE/Ethernet |
| **RS485 Soil Sensor (รุ่นวัด Temp & Humidity)** x2 | ตั้ง Slave ID **1** (แปลงซ้าย) และ **2** (แปลงขวา) |
| โซลินอยด์วาล์วน้ำ x2 | ต่อกับรีเลย์ **CH1** (ซ้าย) และ **CH2** (ขวา) |
| แหล่งจ่ายไฟ | ตามสเปกบอร์ด / PoE และไฟเลี้ยงวาล์ว-เซนเซอร์ |

### การเชื่อมต่อ

| ฟังก์ชัน | ขา / ค่า |
|---|---|
| RS485 RX / TX | GPIO **18** / GPIO **17** (UART1) |
| RS485 ตั้งค่า | **4800 bps, 8N1**, Modbus RTU (Function `0x03`) |
| รีเลย์ (TCA9554, I²C) | SDA = GPIO **42**, SCL = GPIO **41**, Address `0x20` |
| RTC (PCF85063) | I²C Address `0x51` |
| วาล์วแปลงซ้าย / ขวา | รีเลย์ CH**1** / CH**2** |

### การอ่านค่าเซนเซอร์

อ่าน 2 รีจิสเตอร์เริ่มที่ `0x0000` แล้วหารด้วย 10

| รีจิสเตอร์ | ค่า | หน่วย |
|---|---|---|
| `0x0000` | ความชื้นดิน | % |
| `0x0001` | อุณหภูมิดิน | °C |

ค่าที่อยู่นอกช่วง (ความชื้น 0–100 %, อุณหภูมิ -40–80 °C) หรือ CRC ผิด จะถูกนับเป็นอ่านไม่สำเร็จ

แต่ละแปลงตั้งค่าได้อิสระ ทั้งจาก Web Portal และจากแอป Blynk

|---|---|---|---|
| ดินร่วนปนทราย | 30 % | 45 % | 15 % |
| ดินร่วนมาตรฐาน | 42 % | 60 % | 22 % |
| ดินเหนียว / ดินร่วนเหนียว | 52 % | 70 % | 32 % |
| วัสดุปลูก / ขุยมะพร้าว | 55 % | 75 % | 35 % |
| กำหนดเอง | ตั้งเอง | ตั้งเอง | ตั้งเอง |

| กลุ่มพืช | ตัวอย่าง | Pulse เปิด / พักน้ำ | รดสูงสุด/วัน | อุณหภูมิดินสูงสุด |

## ระยะการเจริญเติบโต (Growth Stage)

- ระบบนับ **DAP (วันหลังปลูก)** จากวันที่ปลูกที่ตั้งไว้ โดยใช้ RTC ที่ซิงก์เวลาจาก NTP (เขตเวลา UTC+7)
- มี **4 ระยะ** ต่อแปลง แต่ละระยะมีวันสิ้นสุด (`endDAP`) เป็นตัวบอกว่า "ตามตำราควรอยู่ระยะไหน"
- **ผู้ดูแลเป็นคนเลือกระยะปัจจุบัน** (ผ่าน Web Portal หรือ Blynk) — เฟิร์มแวร์ **ไม่เลื่อนระยะเอง** เพื่อให้รดน้ำตรงกับสภาพพืชจริง ไม่ใช่ตรงกับปฏิทินอย่างเดียว
- มีสถานะ **ไม่ได้ปลูก / พักแปลง (Unplanted)** ซึ่งจะไม่นับ DAP และพักระบบรดน้ำอัตโนมัติ
- เมื่อเลือกพรีเซ็ตกับแปลงที่ว่าง ระบบจะเริ่มนับวันปลูกจากวันนี้
- มีปุ่ม **รีเซ็ต DAP** และ **รีเซ็ตเวลารดสะสมของวัน** แยกต่อแปลง

ตัวอย่างค่า `endDAP` ของแต่ละกลุ่มพืช (ระยะ 1 → 4):

| กลุ่มพืช | สิ้นสุดที่ DAP |
|---|---|
| ผักกินใบ / สลัด | 10 → 25 → 40 → 50 |
| พริก / มะเขือ | 15 → 45 → 85 → 120 |
| เมล่อน / พืชเถาแตง | 15 → 40 → 70 → 85 |
| สมุนไพร / กะเพรา | 15 → 45 → 80 → 120 |

## หลักการรดน้ำอัตโนมัติ

ระบบรดแบบ **เป็นรอบสั้น ๆ + พักให้น้ำซึม** (Pulse / Soak) เพื่อลดน้ำไหลทิ้งและให้ความชื้นอ่านค่าได้สมจริง

```
IDLE ──(ความชื้น < Low)──► WATERING ──(ครบเวลา Pulse)──► SOAKING
  ▲                           │                              │
  │◄──(ความชื้น ≥ High)───────┘                              │
  │◄──(พักครบ และความชื้น ≥ High)────────────────────────────┤
                          WATERING ◄──(พักครบ แต่ยัง < High)──┘
```

1. ความชื้นต่ำกว่าเกณฑ์ **Low** → เปิดวาล์ว (Pulse #1)
2. ครบเวลา Pulse → ปิดวาล์ว แล้ว **พักน้ำซึม**
3. พักครบ ถ้ายังต่ำกว่า **High** → รดรอบต่อไป ถ้าถึง High แล้ว → จบรอบ
4. ถ้าความชื้นถึง High ระหว่างรด → ปิดวาล์วทันที

### โหมดของแต่ละแปลง

| โหมด | การทำงาน |
|---|---|
| **OFF** | ไม่รดน้ำ |
| **AUTO** | รดตามความชื้นและโปรแกรมที่ตั้งไว้ |
| **MANUAL** | สั่งเปิดวาล์วเอง ปิดอัตโนมัติเมื่อครบเวลาที่ตั้ง (1–60 นาที) |

มีสวิตช์ **Master** ปิดการทำงานทั้งระบบพร้อมกันได้ (ใช้กับการสั่ง Manual ด้วย)

## ระบบความปลอดภัย

| กรณี | ระบบทำอะไร |
|---|---|
| **วาล์วเปิดค้างเกินกำหนด** | ปิดวาล์วฉุกเฉินเมื่อเปิดเกิน (เวลา Pulse หรือเวลา Manual ที่มากกว่า) + 2 นาที แล้วเข้าสถานะ FAULT |
| **เซนเซอร์หลุด / อ่านไม่ได้** | เข้าสถานะ FAULT พักการรดอัตโนมัติ และแจ้งเตือน (ลองอ่านใหม่ทุก 10 วินาที) |
| **ดินไม่ชื้นขึ้นหลังรด 3 Pulse (ขึ้นน้อยกว่า 2 %)** | ล็อกการรดแปลงนั้น 60 นาที (สงสัยท่อน้ำตัน เซนเซอร์เสีย หรือน้ำไม่มา) |
| **ความชื้นวิกฤต แต่รดไม่ได้** | แจ้งเตือน (เช่น โหมด Off, Master ปิด หรือรดครบโควตาต่อวันแล้ว) |
| **อุณหภูมิดินสูงเกินกำหนด** | แจ้งเตือน |
| **รดครบเวลาสูงสุดต่อวัน** | หยุดรดอัตโนมัติของวันนั้น |
| **ไฟดับ / บอร์ดรีสตาร์ท** | ปิดวาล์วตอนเริ่มระบบ, คืนค่าเวลารดสะสมของวันเดิม, มี Task Watchdog 15 วินาที |

การแจ้งเตือนชนิดเดียวกันจะมีช่วงพัก (cooldown) 30 นาที เพื่อไม่ให้ส่งซ้ำถี่เกินไป

ค่าที่ตั้งทุกครั้งจะถูกตรวจสอบ เช่น Low ต้องน้อยกว่า High, Pulse 1–30 นาที, พัก 1–120 นาที, รดสูงสุดต่อวัน 1–600 นาที, `endDAP` ของแต่ละระยะต้องเพิ่มขึ้นเรื่อย ๆ

## การติดตั้งและอัปโหลด Firmware

### สิ่งที่ต้องมี

- [VS Code](https://code.visualstudio.com/) + ส่วนขยาย **PlatformIO** (หรือ Arduino IDE)
- สาย USB เชื่อมต่อบอร์ด
- บัญชี [Blynk](https://blynk.io/) (ถ้าต้องการควบคุมผ่านอินเทอร์เน็ตและแอปมือถือ)

### ด้วย PlatformIO (แนะนำ)

```bash
git clone https://github.com/Kurisu001-C/Smart_Farm-Tung-Cham-Roeng.git
cd Smart_Farm-Tung-Cham-Roeng

pio run                 # คอมไพล์
pio run -t upload       # คอมไพล์ + อัปโหลดลงบอร์ด
pio device monitor      # ดู Serial log (115200)
```

> `pio run -t erase` จะล้าง Flash ทั้งหมด รวมถึงค่าตั้งที่เก็บไว้ในบอร์ด (NVS)

- แพลตฟอร์ม: `espressif32 @ 6.9.0` (Arduino-ESP32 core 2.0.17)
- ไลบรารี: `ArduinoJson ^6.21.5` (ติดตั้งให้อัตโนมัติ)
- โค้ดอยู่ในโฟลเดอร์ `SMART_FARM_DUAL_ZONE/`

### ด้วย Arduino IDE

เปิดไฟล์ `SMART_FARM_DUAL_ZONE/SMART_FARM_DUAL_ZONE.ino` แล้วตั้งค่า

- Board: **ESP32S3 Dev Module**
- Flash Size: **16MB**
- Partition Scheme: **16M Flash (3MB APP/9.9MB FATFS)**
- USB CDC On Boot: **Enabled**
- ติดตั้งไลบรารี **ArduinoJson เวอร์ชัน 6.x**

## การใช้งาน

### A) Web Portal (ใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต)

1. เชื่อมต่อ Wi-Fi ชื่อ **`ESP32-SMART-FARM`** (รหัสผ่านเริ่มต้น `farm123456`)
2. เปิดเบราว์เซอร์ไปที่ **http://192.168.4.1**
3. ล็อกอิน (HTTP Basic Auth) ผู้ใช้เริ่มต้น `admin` / รหัสผ่านเริ่มต้น `admin`
4. ใช้งานได้ทั้ง ดูค่าเซนเซอร์, สั่งวาล์ว, ตั้งค่าแปลง, ตั้งค่า Growth Stage, ตั้งค่า Wi-Fi และ Blynk, ดู/ดาวน์โหลด Log

> ⚠️ **ควรเปลี่ยนรหัสผ่านทันทีหลังติดตั้ง** ทั้งรหัส Wi-Fi ของบอร์ดและรหัสผู้ดูแล เพราะค่าเริ่มต้นเป็นค่าสาธารณะใน repo นี้

### B) ผ่านอินเทอร์เน็ตด้วย Blynk (ควบคุมจากที่ไหนก็ได้)

1. เข้า Web Portal → ตั้งค่า **Wi-Fi (SSID / Password)** ของโรงเรียน และ **Blynk Auth Token** แล้วบันทึก (บอร์ดจะรีสตาร์ท)
2. บอร์ดเชื่อมต่อ Blynk Cloud (`blynk.cloud:8883`, MQTT over TLS) ใช้ Template **ARSA2026**
3. เปิดแอป Blynk บนมือถือเพื่อดูค่าและสั่งงาน หรือใช้หน้า HTML สำหรับมือถือในโฟลเดอร์ `Web/`

### C) ตั้งค่าปลูกครั้งแรกต่อแปลง

1. เลือก **ชนิดดิน** และ **กลุ่มพืช** (หรือกด Preset)
2. เลือกโปรแกรม **รดตามช่วงการเจริญเติบโต** หรือ **รดคงที่**
3. ตั้งวันปลูก (หรือกดเริ่มนับจากวันนี้) แล้วเลือกระยะปัจจุบัน
4. ตั้งโหมดเป็น **AUTO**
5. ติดตามค่า DAP และปรับระยะตามสภาพพืชจริง

## Blynk Datastream

แปลงซ้ายใช้ V0–V16 แปลงขวาใช้ V24–V36 (เลขเดียวกัน +20)

| หน้าที่ | แปลงซ้าย | แปลงขวา |
|---|---|---|
| Master (เปิด/ปิดทั้งระบบ) | `V0` | `V0` |
| โหมด (Off / Auto / Manual) | `V4` | `V24` |
| เปิด-ปิดวาล์ว (Manual) | `V5` | `V25` |
| ระยะการเจริญเติบโต | `V16` | `V36` |
| วันหลังปลูก (DAP) | `V6` | `V26` |
| เวลารดสะสมวันนี้ | `V7` | `V27` |
| กลุ่มพืช | `V8` | `V28` |
| ชนิดดิน | `V9` | `V29` |
| ใช้ Growth Stage | `V10` | `V30` |
| รีเซ็ตเวลารดสะสม | `V11` | `V31` |
| รีเซ็ต DAP | `V12` | `V32` |
| Preset | `V15` | `V35` |

ระบบยังรองรับชื่อ datastream แบบข้อความ เช่น `Master`, `Mode_L`, `Valve_L`, `Stage_L`, `DAP_L`, `DailyTime_L` (และ `_R` สำหรับแปลงขวา)

## โครงสร้างโปรเจกต์

```
.
├── platformio.ini                     # ตั้งค่า PlatformIO (ชี้ src_dir ไป SMART_FARM_DUAL_ZONE)

│   ├── SMART_FARM_DUAL_ZONE.ino       # setup/loop, Wi-Fi AP+STA, NTP
│   ├── Config.h                       # ขา, enum, struct, ค่าคงที่ระบบ
│   ├── Hardware.*                     # รีเลย์ (TCA9554), RTC (PCF85063), DAP
│   ├── ModbusSensor.*                 # อ่านเซนเซอร์ RS485
│   ├── ZoneControl.*                  # State machine รดน้ำ + Failsafe
│   ├── Storage.*                      # เก็บค่าถาวร (NVS), Preset ดิน/พืช, ตรวจค่า
│   ├── BlynkManager.*                 # เชื่อมต่อ Blynk (MQTT/TLS)
│   ├── WebPortal.*                    # หน้าเว็บตั้งค่าในบอร์ด
│   ├── AppLog.*                       # บันทึก Log
│   └── *.html                         # หน้า UI สำหรับ Blynk HTML Widget / Web Console
└── Web/
    └── blynk-smartfarm-mobile.html    # หน้า UI สำหรับมือถือ
```

## แก้ปัญหาเบื้องต้น

| อาการ | สิ่งที่ควรตรวจ |
|---|---|
| เซนเซอร์ขึ้น Offline / FAULT | สาย RS485 (A/B สลับหรือไม่), Slave ID (1 และ 2), baud 4800, ไฟเลี้ยงเซนเซอร์ |
| ค่าความชื้นนิ่งหรือไม่ขึ้นหลังรด | ตำแหน่งปักเซนเซอร์, ท่อน้ำ/หัวน้ำตัน, น้ำในถังหมด (ระบบจะล็อก 60 นาที) |
| วาล์วไม่เปิด | โหมดต้องไม่ใช่ OFF, สวิตช์ Master ต้องเปิด, รดครบโควตาต่อวันหรือยัง, ไฟเลี้ยงวาล์ว |
| DAP ไม่นับ / ตั้งวันปลูกไม่ได้ | เวลาจาก RTC ไม่ถูกต้อง — ต่อ Wi-Fi ให้ซิงก์ NTP |
| เข้า Blynk ไม่ได้ | Auth Token, Wi-Fi ของโรงเรียน, Template ID ต้องตรงกัน |
| อยากเริ่มใหม่ทั้งหมด | ใช้ Factory Reset ใน Web Portal (ค่าที่ตั้งไว้จะหาย) |
